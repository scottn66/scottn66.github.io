The Speedy, Q-learning Crawler

A two-jointed robot teaches itself to crawl via Q-learning. The twist: an escalating stack of reinforcement-learning techniques — schedule sweeps, Bayesian optimization, population-based training, DQN, count-based exploration — all plateaued at 42% of optimal. Dynamic programming solves the same problem exactly in three seconds, and a 2002 model-based algorithm (R-MAX) lets RL itself reach 100%. The lesson: the axis that matters is model-free vs. model-based, not which exploration trick you pick.

NER with Viterbi HMM

This project explores Natural Language Processing through probabilistic sequence classification, utilizing Hidden Markov Models (HMMs) to map observable text sequences to their hidden underlying states, such as in Named Entity Recognition. By employing algorithms like Viterbi for efficient decoding and the Forward-Backward algorithm for training, it demonstrates how statistical models can infer hidden linguistic structures and improve text analysis.

Wikipedia Scraper

Three complementary Wikipedia scrapers: sitehopper3_basic.py provides canonical page-key normalization, a SQLite pages/edges graph store, bounded BFS crawling, and a deterministic fake scraper for offline testing. wikiFetcher.py adds a 6-point soup validator that rejects disambiguation pages, missing content, and empty stubs before they enter the cache. wikiSearch.py wraps the MediaWiki search API with content-type validation and JSON decode fallback. Together they form the breadth layer of a cognitive-science knowledge pipeline.

SEP Scraper

Scraper for the Stanford Encyclopedia of Philosophy — the highest signal-per-page source in the stack. Extracts section-keyed content, initial preamble paragraphs, and the hand-curated related_entries cross-reference graph that SEP editors maintain. Includes a DBreader query layer for keyword search over cached articles and an NLTK-based lexicon/bigram analyzer. Each SEP entry yields ~31 curated cross-references vs. Wikipedia's ~834 noisy hyperlinks.

arXiv Scraper

Atom API scraper for arXiv preprints with two entry patterns: category-driven browsing (35 CS subcategories) and free-text keyword search. Downloads PDFs and extracts the first 1–2 pages as text previews via PyPDF2. Normalizes results to structured metadata (arxiv_id, title, authors, categories, abstract). The primary-source verification layer — when a concept page makes an empirical claim, the arXiv pipeline provides the paper that backs it up.
