# scottn66.github.io

Live site: [https://scottn66.github.io/](https://scottn66.github.io/)

Portfolio of Scott Nelson, a data engineer in the Bay Area (MS Applied Data Intelligence, SJSU). The homepage and [resume](https://scottn66.github.io/resume.html) are the hiring front door. Research notes stay as deep-dive pages.

## GitHub Actions

- `manifest.yml` — regenerates `published-corpus.json` when published pages change
- `update-btc-price.yml` — daily BTC price snapshot on the power-law page
- `refresh-power-law.yml` — weekly full power-law pipeline (fit, econometrics, figures)
